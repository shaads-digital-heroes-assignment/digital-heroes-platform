# Digital Heroes (`digital-heroes`)

A full-stack golf performance and charitable giving platform. Subscribers log their latest five Stableford golf scores (`1–45`), commit a mandatory `10%–100%` share of their subscription to a verified charity (or donate `100%` directly), and compete in monthly random or frequency-weighted prize draws with automated jackpot rollovers.

---

## Core Engineering Highlights

- **Cryptographic Authentication (`bcryptjs` + JWT):** Passwords are hashed using 12-round `bcryptjs` salts (`auth.routes.ts`, `seed.ts`) with automatic in-place hash upgrading for legacy seeded accounts and stateless 7-day JWT authorization (`auth.ts`).
- **Database-Enforced 5-Score Rolling Window:** A PostgreSQL `AFTER INSERT` trigger (`enforce_five_scores_limit` in `001_initial_schema.sql`) guarantees each user retains at most 5 Stableford scores (`1–45`), automatically pruning the oldest score when a 6th round is logged.
- **Dual-Mode Prize Draw & Jackpot Rollover Engine:** Supports both pure random draws and inverse-frequency weighted draws (`draw.routes.ts`), splitting the prize pool `40% / 35% / 25%` across 5-match, 4-match, and 3-match tiers while rolling unclaimed 5-match jackpots forward.
- **Zero-Dependency Serverless Bundling:** The TypeScript Express server compiles via `esbuild` into a single `server/api/index.js` artifact connected to the Supabase Transaction Pooler (`:6543`) for instant cold starts on Vercel.

## Quickstart & Deployment

### 1. Backend Setup (`server/`)
```bash
cd server
npm install
npm run db:seed
npm run dev
```

To bundle and deploy the backend to Vercel:
```bash
npx esbuild src/server.ts --bundle --platform=node --target=node20 --format=cjs --outfile=api/index.js --external:pg-native
npx vercel --prod
```

### 2. Frontend Setup (`client/`)
```bash
cd client
npm install --legacy-peer-deps
npm run dev
```

To build and deploy the frontend to Vercel:
```bash
npm run build
npx vercel --prod
```
